HTML Post Example

This is an example of a post written in pure HTML instead of Markdown. You have complete control over the markup and styling.

Why Use HTML Posts?

HTML posts give you more flexibility for:

  • Custom layouts and styling
  • Interactive elements
  • Embedded content
  • Complex formatting

Code Blocks Work Too

Syntax highlighting still works in HTML posts:

function greet(name) {
    console.log(`Hello, ${name}!`);
    return true;
}

// Call the function
greet('World');

TypeScript Example

interface User {
    id: number;
    name: string;
    email: string;
}

function createUser(name: string, email: string): User {
    return {
        id: Math.random(),
        name,
        email
    };
}
